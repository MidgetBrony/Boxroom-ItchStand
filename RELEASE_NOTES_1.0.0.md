# The Itch Stand 1.0.0

The first stable release turns BOXROOM's native video-rental rack into a configurable itch.io discovery stand.

- Uses native BOXROOM shelves, GameBox cases and inspect-in-place interaction.
- Scans a paginated itch.io catalogue instead of repeating the same 29 RSS entries.
- Adds Mod Settings for price, genre, platform, tags and catalogue depth; Free remains the default.
- Downloads real cover art, up to three screenshots and richer game-page descriptions.
- Refreshes cases quickly, then completes description and screenshot enrichment in the background.
- Includes a physical refresh case and opens selected games on their itch.io pages.
- Supports BOXROOM Hot Reload without accumulating duplicate custom games.

Requires ModsPanel 2.4.2 or newer.
